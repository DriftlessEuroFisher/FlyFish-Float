Tailwater to TrailWater

Six ways to animate adding the r, each paired with a different spot on the site. Every one ends on exactly TrailWater (river-blue r, bold W). Each card is a live preview; open the full demo to see it inside a page.

Your device has reduced motion turned on, so every preview shows its finished state and does not loop. That is the same fallback the real page would use.
